# BetterDefect v0.11.15

适用版本：

- 手机：杀戮尖塔 2 v0.103.2
- 电脑：杀戮尖塔 2 v0.107.1

本版主要修复：

1. 改造版“吞噬暗影+”由生成 2 个黑暗球改为生成 3 个黑暗球，保证升级收益。
2. 取消改造版“循环”在只有一个充能球时只能触发一次的限制；单球同时作为最左侧和最右侧球，效果会触发两次。
3. 将改造状态恢复逻辑合并到稳定的持久化补丁中，解决重启或读取存档后百科大全显示已启用、实际效果未启用的问题。
4. Android v103 跳过会导致原生崩溃的卡池/稀有度属性 Getter Detour，改用无 Detour 的数据更新方式。
5. Android 启动补丁队列精简为 32 个补丁类，降低 Harmony/MonoMod 在手机启动阶段的崩溃概率。

安装方法：

1. 解压对应平台压缩包。
2. 将整个 `BetterDefect` 文件夹放入游戏的 `mods` 目录。
3. 确认目录结构为 `mods/BetterDefect/BetterDefect.json`。
4. 覆盖安装不会清除卡面选择、禁用状态、动态出率或改造选择。
