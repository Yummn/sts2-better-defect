# BetterDefect v0.11.12

适用版本：

- 电脑版：Slay the Spire 2 v0.107.1
- 手机版：Slay the Spire 2 v0.103.2

## 本次修复

- 修复重启游戏后百科大全仍显示“改造已启用”，但实战卡牌恢复为原版效果的问题。
- 原因是手机版为避免 Harmony AOT 启动崩溃，会分批延迟安装补丁；卡牌数据库或存档可能在补丁队列完成前创建出未改造的卡牌实例。
- Android 延迟补丁队列完成时，现在会重新刷新所有标准卡牌模型及当前已加载的牌堆。
- 每次完整载入一局、同步玩家存档后，也会按持久化的启用状态重新套用实际改造数值。
- 不会清空或重置现有的卡图、禁用选择、动态出率及改造启用记录。

## 验证

- PC v0.107.1 自动实测：
  - 构造“百科显示启用，但已加载冰寒为原版 1 费/6 伤害”的重启竞态状态。
  - 恢复逻辑实际扫描牌堆并将其改回 2 费/12 伤害。
  - 持久化状态与实际效果最终一致，测试通过。
- PC v0.107.1 与 Android v0.103.2 分别编译成功。
- 双平台离线回归审计：193/193。

## 安装

解压对应平台 ZIP，把其中完整的 `BetterDefect` 文件夹复制到游戏的 `mods` 目录并覆盖旧版。不要混用 PC 与手机版 DLL。
