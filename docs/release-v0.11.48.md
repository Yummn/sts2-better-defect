# 更好的故障机器人 v0.11.48

## 修复

- 修复“递归”在 Android 版中无法正常打出、卡牌结算停滞的问题。
- Android 统一出牌分发器现在直接执行“递归”的完整任务，不再回落到不稳定的原生虚调用路径。
- 改造版“递归”会固定同一个最左侧充能球对象，先激发但不移除，再次激发并移除，避免两次激发之间刷新球队列导致目标错位或任务卡死。
- 重新生成黑暗球时继续继承原黑暗球已经积累的激发数值。

## 验证

- 手机 v0.103.2、手机 v0.110.1、电脑 v0.107.1 三套构建均为 0 个错误。
- 三份最终 DLL 均已反编译核对：Android 分发器直接调用 `BdRecursion.PlayCard`，改造递归依次执行同一球对象的 `Evoke(false)` 与 `Evoke(true)`。
- 三个目标版本的游戏程序集均确认存在对应的四参数 `OrbCmd.Evoke` 实现。
- 本轮电脑版实战自动测试未执行到模组加载阶段，因为本机 Steam 停在登录界面；未将平台初始化失败误记为模组测试结果。
