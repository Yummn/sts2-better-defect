# BetterDefect v0.11.10

适用版本：

- 电脑版：Slay the Spire 2 v0.107.1
- 手机版：Slay the Spire 2 v0.103.2

## 本次修复

- 修正“卡牌改造优先级高于附魔”的问题。
- 改造现在只负责确定卡牌的基础/升级规则，附魔会在改造归一化后作为最终修饰器重新应用。
- 附魔移除“消耗”后，普通升级、读档或生成战斗副本不再被改造重新加回“消耗”。
- 同步覆盖附魔对费用、固有、保留、消耗、虚无等持久卡牌属性的修改。

## 验证

- PC v0.107.1 自动实测：
  - 自定义“移除消耗”附魔 + 改造版双倍能量升级后，仍无“消耗”。
  - 官方 Tezcatara's Ember 费用附魔 + 改造版野性升级后，费用仍为 0。
- PC v0.107.1 与 Android v0.103.2 分别编译成功。
- 双平台离线回归审计：187/187。

## 安装

解压对应平台 ZIP，把其中完整的 `BetterDefect` 文件夹复制到游戏的 `mods` 目录并覆盖旧版。不要混用 PC 与手机版 DLL。
