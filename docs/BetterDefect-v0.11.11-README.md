# BetterDefect v0.11.11

适用版本：

- 电脑版：Slay the Spire 2 v0.107.1
- 手机版：Slay the Spire 2 v0.103.2

## 本次修复

- 修复改造版“混沌”永远无法生成玻璃球的问题。
- 原因是 `ModelDb.Orbs` 只列出闪电、冰霜、黑暗、等离子四种标准球，而原版随机球池实际还包含玻璃球。
- 改造版混沌现在显式使用五种完整球池，并继续优先生成当前球位中不存在的种类。
- 卡面描述与百科大全改造说明同步注明随机球包含玻璃球。

## 验证

- PC v0.107.1 自动实测：
  - 将闪电、冰霜、黑暗、等离子标记为已存在后，生产选择器确定返回 `GlassOrb`。
  - 返回的玻璃球经游戏原生 `OrbCmd.Channel` 实际加入战斗球位，球位结果为 `[LightningOrb, GlassOrb]`。
- PC v0.107.1 与 Android v0.103.2 分别编译成功。
- 双平台离线回归审计：187/187。

## 安装

解压对应平台 ZIP，把其中完整的 `BetterDefect` 文件夹复制到游戏的 `mods` 目录并覆盖旧版。不要混用 PC 与手机版 DLL。
