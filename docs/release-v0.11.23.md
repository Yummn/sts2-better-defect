## BetterDefect v0.11.23

修复改造版“野性”让 0 费能力牌回手后变透明、缩放为零或被删除的问题。

- 根因是能力牌的飞行动画直接操作真实卡牌节点：动画结束时会把节点缩放到零并释放。
- 野性回手时，手牌系统复用了同一个真实节点，所以回手后的卡牌仍会被旧动画隐藏或删除。
- 现在会标记正在被野性回手的卡牌，真实节点只交给手牌区管理。
- 能力牌飞行动画改为使用独立的视觉克隆，避免与 `NCard.FindOnTable` 查找真实卡牌节点发生冲突。
- PC v0.107.1 实战验证：0 费“碎片整理”回手后仍是原节点，手牌中只有一个匹配节点，缩放 `(1, 1)`、透明度 `1.00`、可见且未进入删除队列。
- Android v0.103.2 与 PC v0.107.1 均已独立编译；双平台离线审计 212/212 通过。
