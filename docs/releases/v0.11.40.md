# BetterDefect v0.11.40

## 修复

- 取消循环改造版对同一颗充能球只能触发一次的限制。
- 回合开始时分别读取视觉最左侧和最右侧位置并独立触发；当球位只有一颗球时，该球会按两个边缘位置触发两次。
- 保留多层循环的重复触发逻辑，每层仍按上述规则执行。

- Android v0.110.1
