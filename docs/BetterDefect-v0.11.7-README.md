# BetterDefect v0.11.7

适用版本：

- 手机：Slay the Spire 2 v0.103.x
- 电脑：Slay the Spire 2 v0.107.1
- 不需要 BaseLib

## 本次修复

- **烟囱（改造）**：重复叠加后，每回合第一次由状态牌触发时，额外抽牌数会按烟囱层数结算。两张烟囱现在造成 8 点伤害并抽 2 张牌，不再只抽 1 张。
- **子程序（改造）**：重复叠加后，每层都会提供 1 点能量；每回合第一次触发时，每层还会各抽 1 张牌。记录采用“卡牌打出前已存在的层数”，避免刚打出的第二张子程序错误地提前参与本次结算。
- **循环（改造）**：重复叠加后，每层都会分别触发一次最左侧和最右侧充能球的被动。
- 百科大全中的三张卡牌描述已补充“每层”表述。

## 同类能力检查

已检查改造能力牌的层数结算：

- 吞噬暗影：按层数重复触发黑暗球被动。
- 冷却剂：格挡按能力层数相乘。
- 创造性 AI：每层各进行一次三选一。
- 回响形态：额外打出次数按层数增加。
- 冰雹风暴：伤害按层数与冰霜球数量相乘。
- 循环、烟囱、子程序：本版已修复并完成实机回归。
- 野性、迭代、雷暴：沿用游戏原生能力层数机制，未发现同类的固定一次结算。

## 安装

解压后，将 `BetterDefect` 文件夹放进游戏的 `mods` 目录，并覆盖旧版同名文件夹。
