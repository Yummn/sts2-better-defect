# BetterDefect v0.11.18

适用版本：

- 手机：杀戮尖塔 2 v0.103.2
- 电脑：杀戮尖塔 2 v0.107.1

## 本次修复

修复 Android v0.103.2 中百科大全只显示原版 88 张故障机器人卡牌、一代复原卡牌全部消失的问题。

手机端为了避免 ARM64 Harmony 启动崩溃，会分帧延迟安装补丁。此前游戏在补丁安装完成前就缓存了原版 88 张卡牌，而补丁完成后没有重建该缓存，因此模组内部虽然已识别 114 张卡，百科大全和实际卡池仍只使用 88 张。

v0.11.18 在延迟补丁安装完成后：

- 重新注入 26 张复原卡牌及其能力；
- 清除 Defect 卡池与 ModelDb 的旧缓存；
- 在 `GenerateAllCards` 补丁生效后立即重建卡池；
- 增加不依赖 Harmony 跳转的直接缓存回填后备路径；
- 写入 `pool=114`、`poolRestored=26/26`、`globalRestored=26/26` 自检日志。

## 安装

1. 选择与游戏平台对应的压缩包。
2. 解压后确认最外层包含 `BetterDefect` 文件夹。
3. 将该文件夹放入游戏的 `mods` 目录并启用。

不要把 PC 包安装到手机，也不要把手机包安装到 PC。
