# BetterDefect v0.11.16 PC 实战验证

测试环境：Steam《杀戮尖塔 2》v0.107.1。

## 测试流程

1. 在实际战斗房间启用“回收”改造。
2. 将充能球栏位重置为 3。
3. 向手牌加入“电击”和改造后的“回收”。
4. 自动选择并消耗“电击”，打出改造后的“回收”。
5. 再生成一张回收并升级，检查升级费用。

## 结果

- 基础费用：1。
- 升级费用：0。
- 稀有度：普通。
- 类型：技能。
- 回收自身：消耗。
- 被选择的手牌：消耗。
- 充能球栏位：3 → 4。
- 能量：3 → 3，未触发原版返还能量。

结论：通过。
