## BetterDefect v0.11.17

### 修复

- 修复手机版在改造版“迭代”等结算后战斗行动队列被异常堵塞，导致卡牌无法继续打出的问题。
- 根因是 v0.11.16 手机资产误用了 PC v0.107.1 编译 DLL，并引用了手机 v0.103.2 不存在的 `ICombatState` 类型。
- 手机包现已严格针对 v0.103.2 API 独立编译；PC 包针对 v0.107.1 API 独立编译。
- 新增手机 DLL 平台元数据检查，防止之后再次把 PC 构建误装进手机包。

### 验证

- 双平台编译均为 0 错误。
- 离线审计 205/205 通过。
- 手机 DLL 的 `ICombatState` 元数据计数为 0。
- Android v0.103.2 真机启动成功，32/32 个 BetterDefect 补丁类安装完成，未再出现本次导致行动队列锁死的类型加载异常。
