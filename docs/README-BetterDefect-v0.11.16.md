# BetterDefect v0.11.16

适用版本：

- 手机：杀戮尖塔 2 v0.103.2
- 电脑：杀戮尖塔 2 v0.107.1

## 本次更新

为一代卡牌“回收 / Recycle”新增百科大全改造：

- 普通稀有度，技能牌。
- 1 费，升级后 0 费。
- 消耗。
- 选择并消耗 1 张手牌。
- 获得 1 个充能球栏位。
- 改造效果完全替换原版“根据被消耗卡牌费用获得能量”的效果。

同时修复改造导致卡牌稀有度变化时，动态出率记录未必能按改造前后稀有度正确迁移的问题。

## 验证

- PC v0.107.1 实战自动验证通过：
  - 回收费用为 1；
  - 稀有度为普通；
  - 被选择的手牌与回收自身均进入消耗牌堆；
  - 充能球栏位由 3 增至 4；
  - 不再返还能量；
  - 升级后费用为 0。
- 双平台二进制离线审计：204/204 通过。

## 安装

1. 选择与游戏平台对应的压缩包。
2. 解压后确认最外层包含 `BetterDefect` 文件夹。
3. 将该文件夹放入游戏的 `mods` 目录并启用。

不要把 PC 包安装到手机，也不要把手机包安装到 PC。
