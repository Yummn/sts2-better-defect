# 更好的故障机器人 v0.11.66（仅手机游戏 v0.111.0）

修复与 RitsuLib 同时安装时改造卡出牌效果失效的问题。RitsuLib 会先接管游戏的 `CardModel.OnPlayWrapper`，旧版 BetterDefect 的中央补丁找不到原始 `OnPlay` 调用；新版改为注册 RitsuLib 的出牌监听器，保留其前后钩子。本包依赖 **STS2-RitsuLib 0.6.2 或更新版本**，不依赖 BaseLib。

安装：把压缩包中的 `BetterDefect` 文件夹放到游戏 `mods` 目录，并确保完整的 `STS2-RitsuLib` 文件夹已安装。电脑版 v0.107.1、手机 v0.110.1 继续使用 v0.11.65 包；不要把 v0.111.0 的 DLL 复制到其他游戏版本。

真机测试（REDMI K80 Pro、游戏 v0.111.0）：四个测试模组可启动并进入机器人首战；改造「寒流」为 2 费、12 伤，实际扣除目标 12 HP 并生成 2 个冰霜球。未逐项重测所有 69 种改造及多模组组合。

与战斗路线求解器共同使用时，当前仅允许无改造或只开启「寒流」改造的有限搜索预览；由于逐状态预测差分尚未完成，求解器不会自动打出路线。不要把这视为对全部 BetterDefect 卡牌的完整适配。
