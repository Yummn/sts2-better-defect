# BetterDefect v0.11.13

适用版本：

- 电脑版：Slay the Spire 2 v0.107.1
- 手机版：Slay the Spire 2 v0.103.2

## 本次改动

- 取消改造版“循环”在只有一个充能球时只能触发一次的限制。
- 只有一个球时，该球同时视为最左侧和最右侧球，因此每层循环会触发它的被动两次。
- 有两个或更多球时行为不变：每层分别触发最左侧与最右侧球一次。
- 多层循环仍按层数重复执行上述逻辑。

## 验证

- PC v0.107.1 自动实测：
  - 球位中只保留1个冰霜球。
  - 1层改造循环的回合开始效果实际调用该球被动2次。
  - 两次调用分别来自左侧触发路径和右侧触发路径。
- PC v0.107.1 与 Android v0.103.2 分别编译成功。
- 双平台离线回归审计：194/194。

## 安装

解压对应平台 ZIP，把其中完整的 `BetterDefect` 文件夹复制到游戏的 `mods` 目录并覆盖旧版。不要混用 PC 与手机版 DLL。
