# BetterDefect v0.11.9

适用版本：

- 手机：Slay the Spire 2 v0.103.x
- 电脑：Slay the Spire 2 v0.107.1
- 不需要 BaseLib

## 本次修复

- **冰雹风暴（改造）**：每个冰霜充能球现在分别产生一次 2（3）点全体伤害，不再把所有冰霜球合并为单次伤害。
- 卡面、改造说明、战斗状态栏统一显示“每个冰霜球分别造成伤害”。
- 同步修复以下改造能力牌仍沿用原版状态栏说明的问题：
  - 野性：0费牌，而非仅0费攻击牌。
  - 迭代：额外注明抽牌后消耗该状态牌。
  - 循环：最左侧与最右侧充能球都会触发。
  - 烟囱：每层每回合首次触发会额外抽1张牌。
  - 子程序：每层每回合首次触发会额外抽1张牌。
- 已检查雷暴、吞噬暗影、冷却剂、创造性AI、回响形态；它们的状态栏说明与现有效果一致。

## 验证

- 离线回归：185 项通过，0 项失败。
- 电脑版 v0.107.1 实战自动回归：
  - 卡面与状态栏均显示每个冰霜球分别造成伤害。
  - 2个冰霜球、1个敌人共产生2次独立伤害事件。
  - 每次伤害均为2点，符合未升级改造效果。

## 安装

解压后，将 `BetterDefect` 文件夹放进游戏的 `mods` 目录，并覆盖旧版同名文件夹。
