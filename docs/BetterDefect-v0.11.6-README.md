# BetterDefect v0.11.6

适用版本：

- 手机版：Slay the Spire 2 v0.103.x
- 电脑版：Slay the Spire 2 v0.107.1
- 不需要 BaseLib

## 本次修复

- 修复改造版“迭代”打出后，首次抽到状态牌时可能卡死并导致后续卡牌无法打出的问题。
- 原因是旧逻辑在游戏仍执行 `AfterCardDrawn` 时就把状态牌移入消耗堆，打断了该牌剩余的抽牌生命周期和动画/动作队列。
- 新逻辑等待整次抽牌命令、额外抽牌和 `CardModel.InvokeDrawn()` 全部完成后，再消耗本回合首次抽到的状态牌。
- 保留原有效果：每回合首次抽到状态牌时抽 2（3）张牌，然后消耗该状态牌。

## 验证

- PC v0.107.1 实战自动回归通过：打出“迭代”后抽到“眩晕”，额外抽牌正常完成，眩晕进入消耗堆。
- 随后自动打出“电击”成功，动作队列未锁死。
- 离线源代码、注册表、行为路由和二进制审计全部通过。

## 安装

解压后，把 `BetterDefect` 文件夹放入游戏的 `mods` 目录并覆盖旧版同名文件夹。
